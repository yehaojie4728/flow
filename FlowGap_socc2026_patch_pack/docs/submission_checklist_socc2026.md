## Format

- [ ] ACM acmart template
- [ ] `\documentclass[sigconf,review,anonymous]{acmart}`
- [ ] 9pt font
- [ ] 8.5" x 11" paper
- [ ] PDF <= 10 MB
- [ ] Margins unchanged
- [ ] Inter-column spacing unchanged
- [ ] Line spacing unchanged
- [ ] Paper type subtitle included: Research Full
- [ ] References unlimited and not counted in 12-page body limit

## Anonymity

- [ ] No author names
- [ ] No affiliations
- [ ] No acknowledgments in anonymous draft
- [ ] Self-citations written in third person
- [ ] System/project name anonymized if public elsewhere
- [ ] Artifact/code/data links anonymized or omitted if identity-revealing

## Originality

- [ ] Not under review elsewhere
- [ ] No confidentiality/nondisclosure restrictions
- [ ] Related prior work cited and differentiated
- [ ] Own workshop/technical-report versions cited appropriately and anonymously

## AI usage

- [ ] AI usage recorded in `docs/ai_usage_disclosure.md`
- [ ] All AI-generated text manually reviewed
- [ ] All citations verified
- [ ] All experiments verified
- [ ] Disclosure prepared for camera-ready / HotCRP if required

- [ ] Check exemption
- [ ] Senior author TPMS account ready
- [ ] Reserve reviewer info ready for HotCRP form
