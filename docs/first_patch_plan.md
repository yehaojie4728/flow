## Patch 1: Adapt eBPF Hook Code (Tier 1 + Tier 2)

**Goal:** Extract working eBPF hooks from `trace_memcpy_numa.py` into FlowGap's collector module, and extend for async memcpy.

### Step 1.1: Extract BPF C program

- Source: `external/reference_repo/src/trace_memcpy_numa.py` line ~120 ("int trace_set_device...") through line ~260 ("events.perf_submit...")
- Extract the inline C string into a standalone file: `src/collector/ebpf_hooks/memcpy_hook.c`
- Parameterize `min_size` via a template variable (already supported).
- Add stub fields for `path_id` (u32), `link_bitmap` (u64), `quality_flags` (u32) — set to 0 in BPF, computed in user-space.

### Step 1.2: Add async memcpy hooks

- Create `src/collector/ebpf_hooks/memcpy_async_hook.c`:
  - Hook `aclrtMemcpyAsync` entry (uprobe) — similar to `aclrtMemcpy` entry but also record stream_id.
  - Hook `aclrtMemcpyAsync` return (uretprobe) — record submit timestamp only (actual completion unknown).
  - Track `stream_last_submit` in BPF hash map.
- Create `src/collector/ebpf_hooks/stream_hook.c`:
  - Hook `aclrtSynchronizeStream` entry (uprobe) — record stream_id.
  - Hook `aclrtSynchronizeStream` return (uretprobe) — emit sync event with stream completion timestamp.

### Step 1.3: Add alloc/dealloc hooks for address mapping

- Create `src/collector/ebpf_hooks/alloc_hook.c`:
  - Hook `aclrtMallocHost` return (uretprobe) — record (addr, size) for host allocation.
  - Hook `aclrtMallocDevice` return (uretprobe) — record (addr, size) for device allocation.
  - Hook `aclrtFreeHost` entry (uprobe) — record addr for removal.
  - Hook `aclrtFree` entry (uprobe) — record addr for removal.
  - Emit allocation events to a separate perf buffer or as part of the main events buffer.

### Step 1.4: Create BPF loader and library resolver

- Copy `resolve_ascendcl_lib()` from `trace_memcpy_numa.py` lines ~30-80 → `src/collector/lib_resolver.py`.
- Copy `resolve_bpf_cflags()` → same file.
- Create `src/collector/bpf_loader.py`:
  - Load all 3 BPF programs.
  - Attach uprobes/uretprobes for all target APIs.
  - Open perf buffers for all event streams.
  - Provide unified event iterator.

### Step 1.5: Create FlowEvent schema

- Create `docs/collector_schema.md`:
  - Document FlowEvent binary format (from `docs/outline.md` §4.1.2).
  - Document raw trace CSV format (extended from HostDiagV2's 11-column format).
  - Document agg trace format.

## Patch 3: Event Normalizer (Tier 2)

**Goal:** Adapt event normalization logic from `trace_memcpy_numa.py` into FlowGap's normalizer.

### Step 3.1: Implement address map

- Create `src/normalizer/address_map.py`:
  - Maintain (addr, size) → (device_id, is_host) mapping.
  - Populated from alloc hook events (`aclrtMallocHost`, `aclrtMallocDevice`).
  - Removed by free hook events (`aclrtFreeHost`, `aclrtFree`).
  - Fallback: use `current_device` from BPF hash when address mapping is unknown.

### Step 3.2: Implement event normalizer

- Create `src/normalizer/event_normalizer.py`:
  - For each raw event:
    1. Resolve `src_dev`, `dst_dev`, `src_numa`, `dst_numa` using address_map + topo.
    2. Infer `direction` from `kind` (same logic as original: kind 0=H2H, 1=H2D, 2=D2H, 3=D2D).
    3. Compute `path_id` from (src_dev, dst_dev, direction, src_numa, dst_numa).
    4. Compute `link_bitmap` from topo.
    5. Set `quality_flags`: unknown_path, async_uncertainty (if event is async), timestamp_jitter (if wall clock vs monotonic delta is large).
  - Output normalized `FlowEvent` struct.

### Step 3.3: Implement probe-aware intervalization

- Create `src/predictor/intervalization.py` (NOTE: this logically belongs to predictor, but is needed for normalizer output):
  - For each path/link, maintain busy intervals from normalized events.
  - Merge gaps < T_probe_min + safety_margin.
  - Output per-path, per-link busy-idle timeline.
