## Testing strategy

Three tiers of tests, from fastest to slowest:

| Tier | Name | Runtime | When to run | Requires Ascend? |
|---|---|---|---|---|
| 1 | Unit tests | < 1 min | Every file save | No |
| 2 | Integration tests | < 5 min | Before commit | No (uses synthetic data) |
| 3 | System tests | 1-24 hours | Before experiment runs | Yes (eBPF + probe executor) |
| 4 | Evaluation tests | Days | Before paper writing | Partially |
