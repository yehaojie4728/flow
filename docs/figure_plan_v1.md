## Figure generation pipeline

```text
Raw trace (CSV) → trace_parser.py → normalized events
                                        ↓
           synthetic_workload_gen.py ← params.yaml
                                        ↓
           gap_predictor.py → predictions.csv
                                        ↓
           probe_scheduler.py → probe_results.csv
                                        ↓
           evaluation/plot_*.py → figures/*.pdf
```

- `matplotlib` — primary plotting
- `seaborn` — CDF, heatmap styling
- `scientific-visualization` skill — ACM-compatible figure styling (grayscale-safe, 9pt labels)

- 9pt base font size
- Grayscale-safe colors (use patterns / line styles as fallback)
- PDF vector output
- Legend inside figure bounds
- No AI-generated decorative elements
