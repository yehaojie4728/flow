### Python dependency

Uses `/usr/bin/python3` (conda env does not see yum-installed bpfcc).

### Key design decisions

1. BPF C programs are separate `.c` files (not inline Python strings), loaded by the Python loader.
2. `min_size` is parameterized via C preprocessor `#define` or Python string formatting before load.
3. `path_id` and `link_bitmap` are set to 0 in BPF, computed by normalizer in user-space.
4. `quality_flags` initialized to 0 in BPF, set by normalizer.
5. Event structure uses `u64` timestamps (ktime_get_ns), not wall clock.
6. Ring buffer uses `BPF_PERF_OUTPUT` (compatible with bpfcc on 4.19 kernel without BTF).

### Known limitations (from environment probe)

- Kernel 4.19, no BTF → bpfcc compiles BPF C at runtime (works, but slower startup).
- `libascendcl.so` is stripped → dynamic symbols (`nm -D`) available, which is sufficient for uprobe.
- `aclrtMallocDevice` symbol missing → use `aclrtMalloc` instead (same as HostDiagV2).

**Purpose:** Parse raw events, normalize to structured FlowEvent, build per-path busy-idle timelines with probe-aware intervalization.

### Files

### Component interfaces

```
raw_parser.parse_csv(path) -> Iterator[RawEvent]
raw_parser.parse_binary_buffer(buf) -> Iterator[RawEvent]
address_map.lookup(addr) -> (device_id, is_host)
address_map.insert(addr, size, device_id, is_host) -> None
normalizer.normalize(raw_event, addr_map, topo) -> FlowEvent

timeline.get_gaps(path_id) -> List[Gap]
intervalizer.merge_micro_gaps(intervals, T_probe_min, margin) -> List[BusyInterval]
async_estimator.estimate_async(event, stream_last_end, bw_model) -> (ts_start_est, ts_end_est)
```

### Key design decisions

1. **Address map is incremental** — populated from malloc/free hooks. Unknown addresses get `quality_flags |= QF_ADDRESS_UNMAPPED`.
2. **Path ID enumeration** is deterministic: `path_id = hash(src_dev, dst_dev, direction, src_numa, dst_numa)` using a lookup table initialized from topology.
3. **Interval tree** uses sorted list / `bisect` for O(log n) insertion per path.
4. **Micro-gap threshold** = `T_probe_min + margin`, where `T_probe_min` is the minimum probe size (tiny latency, ~50 µs on Ascend) and `margin` is configurable (default 100 µs).
5. **Async estimation** uses two timelines:
   - **Conservative:** async interval = [submit_time, stream_sync_time] (for safety decisions).
   - **Estimated:** async interval = [max(submit_time, stream_last_end), submit_time + size/B_path + epsilon] (for model features).
6. **Stream ordering** tracked per-stream via `stream_last_end` map.

### Model architecture

```
Tier 0 (cold start / fallback): phase-aware EWMA
    input: gap_history[path][-K:]
    output: quantile estimate for each horizon

Tier 1 (main model): multi-horizon GBDT survival predictor
    model: GradientBoostingClassifier (sklearn) or CatBoost
    targets: y_h = 1 if gap > h at time t, 0 otherwise (per horizon)
    features: gap_stats, burst_stats, path features, stream features,
              phase features, resource features, data_quality features
    output: S(h | x_t) per horizon

Tier 2 (interpretability, optional): semi-Markov state model
    states: {BURST_START, BURST_MID, GAP_START, GAP_MID, GAP_LONG}
    transition matrix estimated from trace
    output: expected time in GAP states

Calibration (post-processing):
    C_final = min(C_model, C_calib, C_data, C_drift)
    C_calib: empirical bin-based (reliability diagram)
    C_data: based on quality_flags stats (drop_rate, unknown_path_ratio)
    C_drift: 1.0 - abs(drift_score)
```

### Scheduler algorithm

```python
def schedule(safe_windows, pending_probes, budget):
    for sw in safe_windows:
        if sw.confidence < ETA_TINY_LATENCY:
            continue  # don't probe

        # select probe type
        if sw.confidence > ETA_BANDWIDTH and sw.g_lower_bound > T_BANDWIDTH + margin:
            ptype = PROBE_TYPE_BANDWIDTH
        elif sw.confidence > ETA_NORMAL_LATENCY and sw.g_lower_bound > T_NORMAL_LATENCY + margin:
            ptype = PROBE_TYPE_NORMAL_LATENCY
        elif sw.confidence > ETA_TINY_LATENCY and sw.g_lower_bound > T_TINY_LATENCY + margin:
            ptype = PROBE_TYPE_TINY_LATENCY
        else:
            continue

        if not budget.consume(ptype, sw.path_id):
            continue  # budget exhausted

        # downgrade check
        if sw.g_lower_bound < estimate_probe_duration(ptype, sw.path_id) + margin:
            ptype = downgrade(ptype)

        # cancellation check: any new busy events for this path since prediction?
        if has_new_busy_event(sw.path_id, sw.t_publish):
            cancel(pending_probes.get(sw.path_id))
            continue

        yield ProbeDecision(allowed=True, probe_type=ptype, path_id=sw.path_id, ...)
```

## Risk register

| Risk | Impact | Mitigation |
|---|---|---|
| Async memcpy hooks fail on CANN 8.5.0 | Module 1 incomplete | Fall back to sync-only predictor; document limitation |
| Predictor overfits to synthetic traces | RQ2-RQ4 not credible | Validate on real traces before claiming results |
| GBDT inference too slow for online use | Module 3 latency > 1ms | Use EWMA fallback; batch predictions; consider lighter model |
| Budget enforcement reduces probe count too much | RQ6 detection recall drops | Failure-aware mode: lower eta temporarily |
| Real traces not available before deadline | All RQs blocked | Proceed with synthetic evaluation; clearly label as synthetic in paper |
| bpfcc not working on conda Python | Module 1 can't start | Use /usr/bin/python3 (confirmed working) |
