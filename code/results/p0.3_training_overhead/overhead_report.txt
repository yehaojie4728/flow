# P0.3: Training Overhead Analysis

**方法**: 基于 probe_live.log 估算探针开销

**训练时长**: 1200 秒 (20 分钟)
**探针总数**: 488 次
  - 延迟探针: 385 次 (平均 121.1 µs)
  - 带宽探针: 103 次 (平均 7041.7 µs, 19.3 GB/s)

## 开销分析

| 指标 | 数值 |
|------|------|
| 探针总执行时间 | 0.772 秒 |
| 训练总时长 | 1200 秒 |
| **开销百分比** | **0.0643%** |

## 解读

FlowGap 探针系统在 20 分钟训练期间执行了 488 次探针测量,
总开销为 0.772 秒,占训练时长的 **0.0643%**。

**结论**: FlowGap 对训练的影响极小,开销 < 0.5%。
